# 基于深度学习的β-内酰胺酶碳青霉烯耐药性预测研究

> 对 6305 条 CARD β-内酰胺酶记录训练深度模型，预测其碳青霉烯耐药表型。

## 数据一览

| 文件 | 行数 | 用途 |
|---|---|---|
| `data/p02_main.tsv` | 6304 | 主训练集 |
| `data/p02_ext1.tsv` | 10250 | 外部验证集 1 |
| `data/p02_ext2.tsv` | 29 | 外部验证集 2 |

数据来源：CARD 抗生素耐药数据库（β-内酰胺酶）


## 技术路线（摘要）

化合物 **Morgan 分子指纹 (2048 维)** ⊕ 靶点 **ESM2-150M 蛋白语言模型嵌入 (640 维)**
→ **GPU 多层感知机**（动态扩缩批训练）→ 活性档位预测（HIGH/MOD 或多分类）。

- 内部验证：主训练集 80/20 分层切分
- 外部验证：ext1 / ext2 两个独立通道全量推理
