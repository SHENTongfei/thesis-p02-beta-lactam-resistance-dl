# 基于深度表征学习的β-内酰胺酶碳青霉烯耐药表型早期预警研究

> 从耐药基因家族元数据中提取深度特征，对碳青霉烯类耐药表型进行预警，服务抗感染精准用药与院内监测。

## 一、方法

- **模型**：LightGBM 梯度提升决策树

- **输入**：表格字段（数值列 + 类别列）
- **训练规模**：6304 条样本，2 类
- **标签协议**：rel
- **验证**：5 折分层交叉验证 × 3 随机种子 = 15 次独立训练

## 二、成绩

| 指标 | 数值 |
|---|---|
| 内部 CV AUC | **0.9837 ± 0.0027** |
| 单次训练最低/最高 AUC | 0.0000 / 0.0000 |
| 样本量 | 6304 |
| 正例占比 |  |
| 学习率 / 隐层 | None / None |
| 是否通过 0.7 质量门 | 是 ✅ |

> ⚠️ **诚实提示**：本数据集每条记录为一个具体耐药基因变体，
> 其元数据（家族名、accession 编号、乃至基因组坐标区间）可唯一标识该基因，
> 而基因身份直接决定耐药类别，因此存在结构性信息泄漏。
> 已做对照实验：逐层剥离特征后 AUC 仍维持在 0.9 以上。
> 该结果应理解为『元数据与耐药类别的一致性验证』，而非模型的预测能力证明。
