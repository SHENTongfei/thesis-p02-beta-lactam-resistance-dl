# 基于深度表征学习的β-内酰胺酶碳青霉烯耐药表型早期预警研究

> 从耐药基因家族元数据中提取深度特征，对碳青霉烯类耐药表型进行预警，服务抗感染精准用药与院内监测。

> ⚠️ **诚实提示（重要）**：本数据集每条记录为一个具体耐药基因变体，
> 其元数据（基因家族名、accession 编号、乃至基因组坐标区间）可**唯一标识该基因**，
> 而基因身份直接决定耐药类别，因此存在**结构性信息泄漏**。
> 已做对照实验：即使逐层剥离特征、仅保留数值坐标，AUC 仍维持在 **0.9 以上**。
> 报告的 **CV AUC = 0.9837 并非真实的预测能力，而是元数据与耐药类别的一致性记忆**。
> 该结果应理解为『耐药基因身份元数据与表型的一致性验证』，而非可外推的预测模型。
> 若需真实的预测能力，必须引入**化合物分子结构（SMILES / 分子图）**作为特征——当前数据缺失该信号。

## 一、方法

- **模型**：LightGBM 梯度提升决策树

- **输入**：表格字段（数值列 + 类别列）——注意：类别列均为基因身份标识符，非分子结构
- **训练规模**：6304 条样本，2 类
- **标签协议**：rel
- **验证**：5 折分层交叉验证 × 3 随机种子 = 15 次独立训练

## 二、成绩（已诚实降格）

| 指标 | 数值 |
|---|---|
| 名义内部 CV AUC | 0.9837 ± 0.0027（⚠️ 含身份泄漏，不可信） |
| 仅数值坐标（剥离全部标识符） | 仍 > 0.9（基因身份可唯一决定类别） |
| 是否构成有效预测模型 | **否（存在结构性信息泄漏）** |
