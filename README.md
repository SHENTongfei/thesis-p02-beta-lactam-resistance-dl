# 基于机器学习的小分子 HIV 整合酶抑制剂活性预测

> 结合 Morgan 分子指纹与 LightGBM 梯度提升树，对化合物抑制 HIV 整合酶的活性进行预测，为抗感染药物发现提供计算支撑。

## 一、方法

- **模型**：LightGBM 梯度提升树（Morgan 分子指纹）
- **输入**：Morgan 分子指纹（2048 bit）
- **训练规模**：737 条样本，2 类
- **标签协议**：act（活跃 / 非活跃）
- **验证**：5 折分层交叉验证 × 3 随机种子 = 15 次独立训练

## 二、成绩

| 指标 | 数值 |
|---|---|
| 内部 CV AUC | **0.9671 ± 0.0123** |
| 样本量 | 737 |
| 正例占比 | 0.417 |
| 是否通过 0.7 质量门 | 是 ✅ |
